# mines

多人扫雷服务器

[即刻体验](https://mines.initenc.cn/)

## 项目架构

- 后端 golang-fiber
- 前端 Vue

## 游戏玩法与特性

- **注册登录系统**: 玩家首次访问即需注册账号以保存积分与进度。如在服务端已正确配置 SMTP，系统还提供基于电子邮件的密码找回功能。
- **多人实时同步**: 所有玩家共同在一个巨型地图上进行扫雷。每个人的点击和标记动作都通过 WebSocket 实时反映到所有人的屏幕上，主打协作（或是竞争抢分）。
- **丰富的道具系统**: 游戏过程中有几率获得特色道具，助你更快清扫雷区：
  - 🛠️ **探测仪**（主动道具）：选中并使用后，显示指定区块周围 `5x5` 范围内的地雷分布，效果持续 10 秒。
  - ⚡ **雷之奥义**（主动道具）：选中并使用后，瞬间自动扫清指定区块周围 `7x7` 范围，其中的地雷会被自动插旗标记。
  - 💯 **双倍积分**（被动道具）：获得后立即生效，在接下来的 10 秒内所有的扫雷得分都将翻倍计算。
  - 🛡️ **护盾**（被动道具）：获得后永久生效直至损耗，可替你抵挡一次踩雷惩罚，且效果可叠加。

## 工作原理

- **后端 (`golang-fiber`)**：负责世界地图的初始化、雷区扫荡逻辑校验、分数统计、用户数据保存以及道具发放。
- **前端 (`Vue 3`)**：渲染平滑的游戏画布及交互UI。
- **通信方式**：登录等状态性获取基于 HTTP，而核心扫雷动作交互及地图刷新全部通过 WebSocket 的实时广播实现。

## 部署

前往 [GitHub Release](https://github.com/initialencounter/mines/releases/latest) 下载编译好的二进制文件，然后运行即可

如需配置密码重置系统，则需要在 `config.yml` 在配置 smtp 服务器

```yaml
smtp:
  host: "smtp.example.com" # smtp 服务器 host
  port: "587" #smtp端口
  tls: true #是否启用 tls
  username: "your email address" #填写邮箱地址
  password: "your password" #填写密码或授权码, 一般都需要授权码，授权码可以到邮箱后台获取
```
